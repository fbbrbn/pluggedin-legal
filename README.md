# pluggedin-legal

Public legal pages for the **PluggedIn** Android app (`com.pluggedin.app`) —
smart EV charging for Danish electricity prices.

This repository exists only to serve these documents at a stable public URL,
which Google Play requires. **The app's source code is not here.**

| Page | URL |
|---|---|
| Privacy policy | https://fabiolonus.github.io/pluggedin-legal/ |

## Editing

`docs/PRIVACY.md` in the main application repository is the canonical source.
`index.html` here is the published rendering of it — update the source first,
then bring this copy in line, so the two cannot drift apart silently.

Any change to what data the app collects, where it is sent, or who operates it
**must** be reflected here before that version is released. The policy states
that commitment explicitly, and Play holds you to it.
